==================================================

14. ACCEPTANCE CRITERIA
==================================================

UI считается готовым, если:

1. Открывается раздел "Устройства".
2. Видны все зарегистрированные кассы.
3. Показывается ONLINE/OFFLINE.
4. Есть поиск.
5. Есть фильтр статуса.
6. Можно выбрать несколько касс.
7. Можно открыть настройки кассы.
8. Можно создать FULL configuration.
9. Можно создать 50/50 configuration.
10. Можно выбрать Static/Dynamic.
11. Можно выбрать playlist.
12. Можно задать interval.
13. Можно выбрать target group/cashboxes.
14. Нажатие "Применить" создаёт deployment.
15. UI показывает progress deployment.
16. После SUCCESS отображается актуальная configuration version.
17. После FAILED отображается причина.
18. NO_OP отображается как NO_OP.
19. Интерфейс визуально соответствует предоставленному reference screenshot.
