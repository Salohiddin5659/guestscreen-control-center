# Oqtepa Lavash • GuestScreen Control Center
## Краткая иллюстрированная база знаний (Visual Wiki Runbook v3.2)

---

### 1. Архитектура и быстрый старт
* **Панель управления**: `http://10.0.0.111:8101`
* **Центральный сервер**: `10.0.0.111` (Ubuntu Linux, Docker, FastAPI, PostgreSQL 16)
* **Принцип Zero-Agent**: На кассах не устанавливаются агенты или демоны. Сервер сам подключается по протоколу SSH Windows, обновляет базу `gs.db` и бесшовно обновляет витрину на глазах у гостя без перезапуска программы кассира.
* **Флот**: 43 активных моноблока сети Oqtepa Lavash (100% готовность).

---

### 2. Зоны экранов и точные размеры баннеров (Шпаргалка)

| Режим экрана | Разрешение | Когда показывается | Что отображается |
| :--- | :--- | :--- | :--- |
| **FULL SCREEN (Ожидание)** | **`1024 × 768 px`** (4:3) | Кассир свободен, чек пуст | Полноэкранный имиджевый баннер или слайдшоу новинок. |
| **50 / 50 PROMO (Заказ)** | **`512 × 768 px`** (2:3) | Кассир пробивает чек r_keeper | **Слева (512x768)**: живой чек гостя (защищен).<br>**Справа (512x768)**: промо-баннер допродаж (напитки, комбо). |

> 🚨 **ВАЖНО**: Никогда не используйте баннеры формата 16:9 (1920×1080)! Экран кассы строго 4:3 (1024×768). Неправильные форматы сплющиваются или обрезаются.

### 3. Подключение новой кассы за 2 минуты (Сисадмину)

#### Шаг 1. На кассе в PowerShell от имени Администратора:
```powershell
# 1. Установка OpenSSH Server
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

# 2. Автозапуск службы SSH
Set-Service -Name sshd -StartupType 'Automatic'
Start-Service sshd

# 3. Открытие порта 22 в брандмауэре Windows
New-NetFirewallRule -Name 'OpenSSH-Server-In-TCP' -DisplayName 'OpenSSH Server (sshd)' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
```

> 🚨 **ВАЖНО**: У пользователя Windows (`Administrator`) обязательно должен быть установлен непустой пароль! С пустым паролем Windows блокирует вход по SSH.

#### Шаг 2. Регистрация кассы в веб-панели:
1. Зайти в **Кассы (`/devices`)** -> нажать **«+ Добавить кассу»**.
2. Ввести IP-адрес (например, `192.168.129.201`), выбрать филиал, ввести логин и пароль SSH.
3. Нажать кнопку **«SSH тест»**. Сервер автоматически проверит отклик, развернет `sqlite3.exe` и хук live-reload. Статус станет зеленым **Online**.

### 4. Публикация рекламы и волновой деплой (Маркетологу)
1. **Загрузка**: в **Медиатека (`/media`)** загрузить баннер (1024x768 или 512x768). SHA-256 предотвращает дубли.
2. **Шаблон**: в **Рекламные шаблоны (`/playlists`)** создать блок (статичный баннер или слайдшоу со сменой 5–7 сек).
3. **Публикация**: нажать кнопку-самолетик **«Опубликовать»** -> выбрать всю сеть, филиал или нужные кассы.
4. **Волны по 2–4 кассы**: сервер доставляет рекламу пачками по 3 кассы (макс 2 на ресторан), защищая канал интернета.
5. **Повтор неудачных**: если касса была выключена, по завершении нажать кнопку **«Повторить неудачные»** для точечного досыла.

### 5. Резервное копирование и Восстановление
* **Каталог бэкапов**: `D:\GuestScreen Server\`
* **Экстренное восстановление PostgreSQL**:
```bash
ssh root@10.0.0.111
docker exec -i guestscreen_postgres16 psql -U postgres -c "DROP DATABASE IF EXISTS gs_control_center;"
docker exec -i guestscreen_postgres16 psql -U postgres -c "CREATE DATABASE gs_control_center;"
docker exec -i guestscreen_postgres16 psql -U postgres -d gs_control_center < /opt/guestscreen-server/backups/gs_control_center_dump.sql
docker restart guestscreen_fastapi_server
```

### 6. Частые вопросы (FAQ)
* **Касса горит «Оффлайн»**:
  1. Проверьте питание моноблока и сетевой патчкорд.
  2. Проверьте пинг: `ping <IP_КАССЫ>`.
  3. На кассе в PowerShell: `Get-Service sshd` (если выключена — `Start-Service sshd`).
  4. Проверьте актуальность пароля в свойствах кассы в панели.
* **На экране гостя старый баннер**:
  1. Проверьте, запущен ли `GuestScreen.exe`.
  2. Проверьте дату изменения `C:\UCS\GuestScreen\Front\sync_version.txt`.
